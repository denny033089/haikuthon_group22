# SigLIP2-large 쌍둥이(twin) 학습 — sumin, 11/21

`google/siglip2-large-patch16-384`를 **쌍둥이 묶음**으로 추가 학습한 버전.
2번 팀원의 `siglip2-L/train_siglip2_kaggle.py`(sigmoid 손실, 마지막 N층 학습, 규칙 기반 오답 문장)를 기반으로 함.

## 쌍둥이 묶음이란
학습 데이터 4,000개 문장 중 **핵심 단어가 70% 이상 겹치는 문장끼리** 연결한 묶음 (1,382개).
색·위치·개수만 바뀐 거의 같은 문장들이라, 같은 묶음의 그림끼리가 가장 헷갈리는 오답임.

| 묶음 크기 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 개수 | 54 | 711 | 96 | 442 | 38 | 24 | 2 | 15 |

## 바꾼 점
1. **배치 = 쌍둥이 묶음 통째로** 채움 (32쌍) → 같은 배치 안의 쌍둥이 그림·문장이 서로의 오답이 됨
2. **검증 = 쌍둥이 묶음 단위 분할** (묶음의 20%, 시드 0) → 검증 쿼리의 99%가 쌍둥이와 함께 갤러리에 있음 (팀 공통 무작위 500은 24%)
3. 조기 종료 (2 epoch 연속 개선 없으면 중단), WiSE-FT (학습 전·후 가중치 섞기) 비교
4. 텍스트는 공식 방식 (소문자, 64토큰 `max_length` 패딩). 문장 나눠 평균은 zero-shot에서 효과가 없어서 뺌
5. 2차(전체 데이터) 학습도 1차와 같은 8-epoch 코사인 스케줄을 쓰고 5 epoch에서 멈춤

설정: 마지막 **6층** (이미지·텍스트 각각, 24층 중) + 헤드/정규화/logit scale·bias 학습, 단어 사전 고정 (학습 165M / 전체 882M),
lr 1e-5, warmup 50, weight decay 0.01, 배치 32, 오답 문장 문장당 1개, 이미지 증강 없음 (좌우반전·색 변형은 정답을 바꿈)

## 결과 — 1차 (학습 3,238쌍 / 쌍둥이 검증 762쌍, Kaggle T4)

| | 학습 전 (zero-shot) | **학습 후 (epoch 5)** | 변화 |
|---|---|---|---|
| score = (R@1+NDCG@5)/2 | 0.5433 | **0.6399** | **+0.097** |
| R@1 | 0.3766 | **0.4974** | +12.1%p |
| NDCG@5 | 0.7100 | 0.7825 | +7.3%p |
| 쌍둥이 내 정답률 | 0.4069 | **0.5199** | +11.3%p |

| epoch | 1 | 2 | 3 | 4 | **5** | 6 | 7 |
|---|---|---|---|---|---|---|---|
| val score | 0.554 | 0.601 | 0.607 | 0.629 | **0.640** | 0.632 | 0.634 |

| WiSE-FT α | 0.3 | 0.5 | 0.7 | **1.0** |
|---|---|---|---|---|
| val score | 0.588 | 0.608 | 0.624 | **0.640** |

- 같은 zero-shot large가 무작위 500에서는 0.849, 쌍둥이 검증에서는 0.543 → **쌍둥이가 실제 난관**
- zero-shot의 쌍둥이 구별(0.41)은 찍기 수준 → 학습으로 0.52까지 오름. 아직 절반 수준이라 개선 여지 큼
- α=1.0이 최고 → 학습으로 일반 능력을 잃은 흔적 없음, 더 넓게 학습(층 수↑, LoRA)해 볼 여지
- epoch당 약 174초 (T4)

## 결과 — 2차 (4,000쌍 전부, 5 epoch → 제출용)
손실 15.2 → 2.29, epoch당 약 220초. 검증셋이 없어서 점수는 1차 결과를 근거로 함.

## 파일
| 파일 | 설명 |
|---|---|
| `train_twin_siglip2L.py` / `.ipynb` | 학습 노트북 코드 (Kaggle: GPU T4, Internet On, Input = 대회 데이터). `TRAIN_ON_ALL=False` 1차, `True` 2차 |
| `train_twin_siglip2L_run1_executed.ipynb` | **1차 실행 결과 포함** (Kaggle에서 다운로드) |
| `train_twin_siglip2L_run2_executed.ipynb` | **2차 실행 결과 포함** |
| `results/run1_*` | 1차 로그 (`log.json`: epoch별 수치, `.txt`: 출력), `run1_split.json`: 학습/검증 인덱스 |
| `results/run2_*` | 2차 로그 |
| `submission/model.py` | 제출용 `load_model` / `predict` (오프라인 로드, 이미지 디코딩 CPU 4개 병렬, fp16) |
| `submission/make_zip.py` | `python make_zip.py <가중치 폴더> <zip 이름>` → `model.py` + `models/config.json` + `models/<폴더>/` |
